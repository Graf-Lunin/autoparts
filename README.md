# АвтоАксессуары

**Вариант:** 13
**Тема:** Магазин автомобильных аксессуаров
**Специфика:** Подбор по марке и модели автомобиля

## Запуск проекта
Внешние зависимости и сборка отсутствуют. Для просмотра необходимо открыть файл `index.html` в браузере

## Реализованный функционал (для ПР 1)
Проект представляет собой статическую часть сайта, состоящую из 5 страниц:
1. **Главная (`index.html`)**: Навигация, подборка из 6 позиций с изображениями и ссылками
2. **Каталог (`catalog.html`)**: Список из 12 позиций, разметка фильтров (марка, модель, категория) и сортировки
3. **Карточка товара (`item.html`)**: Изображение, описание, таблица характеристик, цена, кнопка добавления в корзину
4. **Корзина (`cart.html`)**: Страница действия пользователя с таблицей выбранных товаров, количеством и итоговой суммой
5. **Контакты (`contacts.html`)**: Контактные данные, режим работы, форма для обратной связи

**Технические требования:**
- Разметка выполнена с использованием семантических тегов HTML5
- Стилизация вынесена в единый файл `style.css`
- Верстка адаптивна
- Изображения оптимизированы, для всех тегов `img` заполнен атрибут `alt`
- Кодировка файлов UTF-8
